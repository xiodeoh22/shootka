# игра шутер
![Shooter](https://raw.githubusercontent.com/Parucnik/shoot/refs/heads/main/icon.ico)
## краткое описание: 
простая стрелялка на **питоне**
# требования:
требует детскую библиоткеу [pygame](https://pypi.org/project/pygame/)
```
pip install pygame
```
# объекты в игре:
1. игрок (базированный гигачад)
2. враги (антибазированные соевые)
3. астероиды (антибаза)
4. пули (просто пули)
5. счетчики
